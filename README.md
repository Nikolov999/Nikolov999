2. Data analysis using Pandas, NumPy and Matplotlib.

Key areas demonstrated:

### ARGUS

A modular Active Directory security review framework written in Go.

ARGUS performs read-only assessment of areas including:

- Kerberos configuration
- privileged groups
- delegation
- Group Policy
- domain trusts
- AD CS
- ACL exposure
- SMB exposure
- remote administration surfaces

The project demonstrates Go development, CLI architecture, Active Directory concepts, LDAP interaction and structured security reporting.

Repository:
https://github.com/Nikolov999/argus
